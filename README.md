# EXE Ice Fishing · assets

Hosted files for the **EXE Ice Fishing** StreamElements widget by form&soul.exe.
The widget loads the engine, art, sounds and fonts from this repository (GitHub Pages).

**Do not rename, move or delete files** — installed widgets load them from these exact paths.

- `engine/icefish.js` — game engine (version in the first line)
- `assets/` — island art, sprite atlases, sounds, fonts
- `index.html` — preview page
